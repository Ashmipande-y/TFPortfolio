# TrackForge

AI-powered construction site asset intelligence and security platform.

## Repository Structure

- `backend/` — FastAPI backend
- `frontend/` — Next.js frontend
- `docs/` — Architecture and project documentation

## Tech Stack

### Backend
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Redis

### Frontend
- Next.js
- TypeScript
